# Регламент перезапуска службы Orbita

Этот регламент описывает единственный поддерживаемый способ перезапуска
службы Orbita. Любой другой порядок действий приводит к рассинхронизации
реестра поездов и требует ручного восстановления.

## Порядок действий

1. Остановить приём новых сборок командой паузы оркестратора.
2. Дождаться, пока оркестратор подтвердит остановку — подтверждение
   обязано прийти в течение 90 секунд.
3. Перезапустить процесс службы Orbita.
4. Снять паузу оркестратора и убедиться, что очередь сборок пуста.

Если подтверждение остановки не пришло за 90 секунд, перезапуск запрещён:
нужно открыть инцидент на команду Replay Guild и приложить журнал
оркестратора за последние 15 минут.

## Ограничения

Перезапуск разрешён только между стадиями поезда. Во время стадии
canary-slice перезапуск запрещён без исключения, подписанного командой
Traffic Stewards.

## Контрольная проверка

После перезапуска выполните контрольный запрос состояния: служба обязана
ответить статусом «готова» не позднее чем через 30 секунд. Ответ с любым
другим статусом означает неуспешный перезапуск, и процедура повторяется
с шага 1 не более двух раз подряд.
